# Finance Helper — бэкенд

Бэкенд личного финансового Telegram Mini App: принимает CSV-выгрузку из Дзен-мани,
пересчитывает суммы в доллары по историческим курсам, считает сальдо месяца,
разбивку по категориям и сравнение плана с фактом.

Фронтенд лежит рядом: `../finance_helper_web`.

## Что нужно сделать руками

### 1. Бот в @BotFather

1. Написать [@BotFather](https://t.me/BotFather) → `/newbot`, задать имя и username.
2. Скопировать токен и положить в `.env` как `BOT_TOKEN=...`.
3. Узнать свой telegram id (например у [@userinfobot](https://t.me/userinfobot)) и вписать
   в `ALLOWED_TELEGRAM_IDS=...`. Пока список пуст, доступ открыт всем — не оставляйте так
   на публичном адресе.
4. После того как аппа доступна по https, задать адрес Mini App:
   `/setmenubutton` → выбрать бота → указать URL.

### 2. HTTPS для Mini App

Telegram открывает Mini App только по https. Для локальной отладки — туннель:

```bash
cloudflared tunnel --url http://localhost:3000
```

Полученный адрес вида `https://xxx.trycloudflare.com` вписать в `WEBAPP_URL` и указать
в BotFather. Для фронтенда собрать бандл с `NEXT_PUBLIC_API_BASE_URL`, указывающим
на публичный адрес API.

## Запуск

### Docker Compose

```bash
cp .env.example .env
docker compose up -d --build
```

Поднимутся `db` (Postgres 16), `api` (миграции + uvicorn на 8000), `bot` и `web` (Next.js
на 3000). Миграции применяются при старте `api`.

### Локально без Docker

```bash
uv sync
uv run alembic upgrade head
uv run uvicorn app.main:app --reload --port 8000
uv run python -m app.bot.main
```

## Заливка выгрузки без бота

```bash
uv run python scripts/import_csv.py ~/Downloads/zen_dump.csv --telegram-id ВАШ_ID
```

Дедупликация идёт по полю `createdDate` из выгрузки, поэтому повторная заливка полного
дампа не создаёт дублей — можно каждый месяц присылать свежий полный экспорт.

## Переменные окружения

| переменная | назначение |
|---|---|
| `DATABASE_URL` | строка подключения SQLAlchemy |
| `BOT_TOKEN` | токен из BotFather |
| `WEBAPP_URL` | https-адрес Mini App, попадает в кнопку бота |
| `ALLOWED_TELEGRAM_IDS` | список id через запятую; пустой список — доступ всем |
| `BASE_CURRENCY` | базовая валюта отчётов, по умолчанию `USD` |
| `EXCLUDED_CATEGORIES` | категории, не попадающие в итоги, по умолчанию `Correction` |
| `INTERNAL_TOKEN` | общий секрет для запросов бота в API |
| `DEV_BYPASS_AUTH` | отключает проверку initData; работает только при `ENV != production` |
| `DEV_TELEGRAM_ID` | от чьего имени работать при обходе авторизации |

## Как устроено

```
app/
  config.py        настройки
  db.py            движок и сессии
  models/          таблицы, денежный тип, перечисления
  auth.py          проверка подписи Telegram initData
  api/             ручки: статистика, транзакции, бюджет, импорт
  services/
    zen_csv.py     разбор выгрузки
    fx.py          курсы валют и пересчёт
    importer.py    импорт с дедупликацией
    stats.py       агрегации (чистые функции)
    budget.py      доход месяца и планы
  bot/             aiogram: приём CSV, напоминание в конце месяца
```

### Курсы валют

Курсы тянутся с графиков Yahoo Finance — одним запросом на валюту за весь диапазон дат,
с кэшем в таблице `fx_rates`. Это важно для исторических данных: ARS за 2023–2026
обесценился в разы, и пересчёт старых месяцев по текущему курсу дал бы бессмыслицу.

Статусы пересчёта у транзакции:

- `ok` — курс на дату операции или перенос последнего закрытия (выходные, праздники);
- `approx` — курс найден дальше по времени либо выведен из привязки
  (BAM жёстко привязана к евро, USDT — к доллару);
- `pending` — курса нет, сумма в долларах неизвестна. Такие операции не попадают
  в итоги, в аппе висит баннер, догрузить можно ручкой `POST /api/fx/backfill`.

### Категории

Хранятся дословно из выгрузки, без нормализации: `«Продукты в магазинах »` с хвостовым
пробелом и `«Продукты в магазинах»` останутся разными категориями, `«Подарок»`
и `«Подарки»` тоже. Это осознанное решение — источником истины остаётся Дзен-мани.
